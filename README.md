# 🎬 Calculadora de Servicios Audiovisuales - AVBudget

Herramienta gratuita para presupuestar servicios de video, fotografía y streaming.

## ✨ Características

- ✅ Cálculo de costos de personal (roles técnicos)
- ✅ Inventario de equipos con depreciación
- ✅ Streaming con múltiples plataformas y switcher
- ✅ Configuración de IVA e ISR (porcentajes personalizables)
- ✅ Exportación a TXT
- ✅ Interfaz moderna y responsive

## 🚀 Uso

1. Ingresa los datos del cliente
2. Configura los servicios (Video, Foto, Streaming)
3. Ajusta equipos y personal
4. Define impuestos y márgenes
5. Exporta el presupuesto

## 🛠️ Tecnologías

- HTML5
- CSS3 (Variables, Grid, Flexbox)
- JavaScript (Vanilla)
